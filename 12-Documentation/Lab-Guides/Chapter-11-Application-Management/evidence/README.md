# Application Management Evidence

Capture sanitized screenshots or records showing:

1. Intune application configuration.
2. Win32 package creation and upload.
3. Install and uninstall commands.
4. Requirement and detection rules.
5. Application assignments.
6. Device installation status.
7. Company Portal availability and installation.
8. Dependencies and supersedence configuration.
9. PowerShell inventory report.
10. Rollback validation.

Redact tenant identifiers, usernames, serial numbers, license keys,
and other confidential information.
