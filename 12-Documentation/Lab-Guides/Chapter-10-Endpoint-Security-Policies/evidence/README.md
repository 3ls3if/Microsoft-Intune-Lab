# Endpoint Security Evidence Checklist

Capture sanitized evidence for:

1. Test group and assignment scope.
2. Defender Antivirus policy settings.
3. Local Defender Antivirus state.
4. Windows Firewall policy and profile state.
5. BitLocker configuration and volume state.
6. Evidence that recovery-key escrow was verified, without exposing the key.
7. ASR policy in Audit mode.
8. ASR rule state and available audit evidence.
9. Intune device policy status.
10. Any policy conflicts and their resolution.
11. Rollback verification.

Redact tenant identifiers, usernames, serial numbers, recovery information,
and other sensitive details when they are not necessary to demonstrate
the lab result.
